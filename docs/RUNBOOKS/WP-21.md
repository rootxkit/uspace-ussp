# WP-21: InterUSS test interfaces, the uss_qualifier runs

Every `uss_qualifier` run against this USSP's test interfaces
(`cmd/test-interfaces`, docs/PLAN.md D13, §6.4) through `make conformance`,
with what was observed (E-04, E-05). The suite decides; nothing here is
described from what it should have said.

## How to run it

```
LAB_DIR=<uspace-lab at deploy/conformance/SOURCE's lab_commit> make conformance
CONFORMANCE_QUALIFIER=off make conformance     # the national suite alone
```

The hook (`scripts/conformance.sh`) builds the image under test and the
separate `uspace-ussp-testif` image, checks that the first has no
`ussp-test-interfaces` and the second has (`scripts/check-images.sh`),
seeds the test operator of `deploy/conformance/test-operator.yaml`
through the national API (`ussp-test-interfaces seed`), starts
test-interfaces (`http://ussp:8087` on the lab network, `/test/*` through
the lab Caddy), checks every declared interface answers 401 without a
credential, starts the lab's mock USS, runs the lab's
`run-qualifier.sh f3411-sp.yaml`, `f3548-scd.yaml` and `f3411-dp.yaml`,
and folds the reports into the suite's run.
