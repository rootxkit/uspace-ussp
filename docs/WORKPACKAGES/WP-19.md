## What to build

- `deploy/conformance/`: compose profile `conformance` with the InterUSS
  DSS (image by digest; its CockroachDB or the single-node setup the
  docs give), a test issuer the DSS trusts (the lab's `uspace-lab`
  simulated issuer, or `uss_qualifier`'s own auth adapter for local
  runs), this USSP's seven processes pointed at it, the fakes for CISP,
  authority and ANSP (from `internal/testfakes`, built as a small
  binary `cmd/testfakes` **not** included in the production image);
  `uss_qualifier` configurations: F3411 v22a Service Provider suite
  (ISA creation, `GET /uss/flights` content and timing, details,
  subscription notifications) with our USSP as the SP participant and
  `uss_qualifier`'s mock DP; F3548 v21 strategic coordination (operational
  intent references, ovn and key semantics, notifications, conflict
  behaviour, priority), constraint processing (notifications from a
  mock constraint manager), with our USSP as a participant and the mock
  USS as the peer; `make conformance` runs them and writes the reports
  under `local/conformance/` (git-ignored); the `conformance` workflow
  (`workflow_dispatch` and tags `v*`) runs the same and uploads the
  reports as artifacts.
- Findings loop: every failed check becomes a `fix(<pkg>): ... [WP-19
  S-M6]` PR with the `uss_qualifier` check name in the body; the suite
  is re-run after each; `docs/RUNBOOKS/conformance.md` records each run
  (date, image digest, `uss_qualifier` commit, pass/fail per scenario).
- Chaos (`05 §6`) run against the compose stack with the lab's
  simulated operators (the lab's generators; this WP only provides the
  stack and the procedure): CISP down 5 min (geo `stale`, new U-space
  authorisations refused after 300 s with `cis_stale`, in-flight
  services continue), authority down (validity cache then `unknown`;
  JWKS cached), DSS down (`pending_dss`; `/uss/flights` still served),
  ANSP down (`manned: unavailable`), NATS down 60 s (ingest spills and
  replays; others unaffected), TimescaleDB down (writer queues),
  `api` down (hot path continues on projections with age), each
  process killed in turn (picture back within 10 s, no duplicate alerts,
  no lost backlog); each outcome recorded with the counters read
  (`dropped_*`, `gap_*`, `degraded_*`) in `docs/RUNBOOKS/chaos.md`.
  Any behaviour that differs from `02`'s failure columns is a finding.

## Safety notes

- The suite runs against test credentials and the lab issuer only; a
  configuration that could point `uss_qualifier` at the staging DSS with
  production-shaped credentials is refused by a check on the config
  file (`USSP_SYSTEM_ID` must contain `TEST` or `DEV` in this profile).
- Nothing in the conformance stack can reach an aircraft; the operators
  are the lab's simulators.
